# 💙 우리의 추억 - 데이트 기록 관리 웹사이트

수원 인계동에서의 소중한 데이트를 기록하고 관리하는 웹사이트입니다.

## 🌟 주요 기능

### 1. 데이트 기록 추가
- **날짜**: 데이트한 날짜 기록
- **장소**: 방문한 장소 입력
- **설명**: 그날 무엇을 했는지 상세히 기록
- **기분**: 당시의 감정을 이모지로 표현

### 2. 통계 기능
- **총 데이트 수**: 지금까지 함께한 데이트 횟수
- **월간 데이트**: 이번 달 데이트 기록 수
- **가장 많이 간 곳**: 가장 자주 방문한 장소

### 3. 데이터 관리
- **로컬 스토리지 저장**: 브라우저에 자동 저장되어 데이터 손실 걱정 없음
- **삭제 기능**: 필요한 기록 삭제 가능

## 🎨 디자인 특징

- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 최적화
- **예쁜 그라데이션**: 보라색 톤의 따뜻한 배경
- **카드 레이아웃**: 직관적이고 깔끔한 구성
- **사진 헤더**: 우리의 추억 사진을 메인 헤더에 배치

## 📱 기술 스택

- **HTML5**: 웹 페이지 구조
- **CSS3**: 반응형 디자인 및 스타일링
- **JavaScript (ES6+)**: 기능 구현 및 데이터 관리

## 🚀 사용 방법

1. **index.html** 파일을 브라우저에서 열기
2. "새로운 데이트 기록하기" 섹션에서 데이트 정보 입력
3. "기록 추가" 버튼 클릭
4. 기록된 데이트가 자동으로 목록에 추가됨
5. 통계가 실시간으로 업데이트됨

## 💾 데이터 보관

모든 데이터는 브라우저의 **로컬 스토리지**에 저장됩니다.
- 같은 브라우저에서만 데이터 조회 가능
- 브라우저 캐시 삭제 시 데이터 손실 가능

## 🌐 배포 방법 (GitHub Pages)

1. GitHub에서 새 저장소 생성 (`date-memories` 또는 원하는 이름)
2. 로컬 저장소 설정:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/date-memories.git
   git branch -M main
   git push -u origin main
   ```
3. GitHub Repository 설정:
   - Settings → Pages
   - Source: Deploy from branch
   - Branch: main, folder: / (root)
   - Save
4. 배포 완료! `https://YOUR_USERNAME.github.io/date-memories` 에서 접속 가능
